# FIFA World Cup Data

My goal was to collect some datasets that capture details on the 2026 FIFA World Cup. Looking at the repository Ron found (https://github.com/jfjelstul/worldcup), which covers up to 2022, some of this data can be used alongside it in order to cover this most recent World Cup (if we want to include data on various world cups in the database).

## Datasets

| Dataset Description | Source | Repository Link |
|----------|----------|----------|
| ```stadiums.csv``` has ```city```, ```stadium_name```, ```total_matches```, ```group_matches```, ```knockout_matches```, and ```capacity``` related to the 2026 World Cup | Wikipedia  |  [stadiums.csv](./Datasets/stadiums.csv) |
| ```group_stage.csv``` has attributes related to the group stage of the 2026 world cup: ```group_pos``` (team rank relative to group), ```team```, ```matches_played```, ```matches_won```, ```matches_tied```, ```goals_for```, ```goals_against```, ```goal_difference```, ```advanced_to_knockout``` (0 or 1), ```group``` (the letter representing the group) | Wikipedia  | [group_stage.csv](./Datasets/group_stage.csv)  |
| ```world_cup_scorers.csv``` tracks players and goals over all world cup matches they participated in. This dataset has attributes ```rank```, ```player_id```, ```player``` (a few instances where only player's last name is included, mostly first and last name), ```teams```,  ```goals``` (this is career totals over all world cups), ```edition_breakdown``` (this lists values in format <year>:<total_goals> and contains a bar delimiter for cases where player has scored in different years) | [worldcupstats.app/world-cup/data](https://www.worldcupstats.app/world-cup/data)  | [world_cup_scorers.csv](./Datasets/world_cup_scorers.csv)  |
| ```matches.csv``` contains details on individual matches that took place during the 2026 World Cup. It contains attributes ```round``` (i.e. group stage, round of 32, ...), ```gameweek```, ```dayofweek```, ```date```, ```start_time```,  ```home_team```, ```away_team```, ```score``` (stored as <home_score>:<away_score>), ```home_score```, ```away_score```, ```attendance```, ```venue```, ```referee```, ```home_formation```, ```away_formation``` (describes how players were arranged on home and away teams, respectively), ```home_manager```, ```away_manager```, ```home_captain```, ```away_captain```, ```home_possession```, ```away_possession```, ```home_sot```, ```away_sot``` (sot = shots on target), ```home_total_shots```, ```away_total_shots```, ```home_saves```, ```away_saves```, ```home_cards_yellow```, ```away_cards_yellow```, ```home_cards_red```, ```away_cards_red```, ```home_fouls```, ```away_fouls```, ```home_corners```, ```away_corners```, ```home_crosses```, ```away_crosses```, ```home_interceptions```, ```away_interceptions```, ```home_offsides```, ```away_offsides```, ```notes```| https://www.kaggle.com/datasets/swaptr/fifa-wc-2026-matches?resource=download and was scraped from https://fbref.com/en/comps/1/schedule/World-Cup-Scores-and-Fixtures) | [matches.csv](./Datasets/matches.csv)|
